# Meeting Transcripts

Automated transcriptions of Timberland Regional Library Board of Trustees and committee meetings, covering 2012 through June 2026.

- **Board meetings:** 216 transcripts (`board-meetings/`)
- **Committee meetings:** 80 transcripts (`committee-meetings/`)

## How these were produced

These transcripts were generated using [WhisperX](https://github.com/m-bain/whisperX) with speaker diarization. The source recordings are public records obtained from TRL via AV CaptureAll.

## Important: verification required

These transcripts are useful for searching and locating relevant moments in meetings, but they are **not verbatim records**. Automated speech recognition introduces errors — misheard words, missed speaker changes, and dropped or garbled phrases are common, especially in multi-speaker board meeting environments.

**Any quote used in the report was manually verified by reviewing the original video recording.** If you are citing or relying on a specific passage, you should do the same. Timestamps in the transcript files correspond to the original recordings and can be used to locate the relevant moment.

## Naming convention

Files follow the pattern `YYYY-MM-DD_description.md`, matching the source video filenames.
